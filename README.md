# Notepad Clone
Notepad Clone is a lightweight, high-performance text editor that is designed for daily use. Ideal for document management and a distraction-free, responsive writing experience, this tool delivers the perfect balance between speed and functionality.

## Technologies Used
* C#
* .Net 10
* WinForms

## Features
* Opening/saving/editing files
* Allows opening files by dragging them on the '.exe', or through the command line
* Unsaved change asterisk indicator, and warning messages to protect your data
* Light/dark mode support
* Find functionality (within the text), with regular expressions support
